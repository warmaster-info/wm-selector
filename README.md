**This is the selector deployed to https://selector.warmaster.info, showing various fixes plus the experimental/developmental lists.** The original project is at https://github.com/dsusco/wm-selector.

A Vue army builder for Games Workshop's Warmaster: https://selector.warmaster.info

## The TL;DR Start

    $ git clone git@github.com:warmaster.info/wm-selector.git
    $ cd wm-selector/
    $ npm ci
    $ npm run serve

That should build and serve up the app at [http://localhost:8080/](http://localhost:8080/).
